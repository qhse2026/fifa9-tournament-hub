# FIFA9 Tournament Universe V47.0.0 — Horizon OS

## Product direction
Horizon OS replaces the persistent admin-dashboard impression with a full-width gaming platform shell. Existing tournament, career, Supabase, Formula and match-engine state remain unchanged.

## Core systems
- Floating product navigation with route-aware accents
- Off-canvas command drawer preserving every existing route
- Command palette with Ctrl/Cmd+K search
- Dynamic canvas network field on the home hero
- Native pointer tilt, scroll reveal, count-up and route-transition effects
- Four visually distinct mode identities: Final Chapter, Manager Career, Formula and Intelligence
- Responsive mobile shell with existing bottom navigation preserved
- Reduced-motion and visibility-aware animation lifecycle
