ENVIRONMENT LIMITATION
----------------------
Headless Chromium in this container cannot complete a full microphone/browser audio test because the runtime has no usable DBus/audio input stack. Wake-word and microphone behavior must therefore be verified on the target Android Chrome / desktop Chrome device after deployment.

IMPORTANT PRODUCT LIMIT
-----------------------
V5.1 uses browser Web Speech Recognition for wake-word detection. Browser/OS policies can suspend microphone recognition when the page is backgrounded or the phone is locked. A native Android companion or dedicated on-device wake engine is required for true lock-screen/background hotword behavior.
